# 🚀 Codeglimpse+ - Real-Time Collaborative Code Editor

Codeglimpse+ is a real-time collaborative code editor built for developers, educators, and teams. It enables users to join coding rooms, write and execute code together, chat live, draw on whiteboards, and work in sync like never before.

---

## 🔧 Tech Stack

- **Frontend:** React.js, Tailwind CSS, HTML/CSS
- **Backend:** Node.js, Express.js
- **Realtime Communication:** Socket.io
- **Editor Support:** Monaco Editor
- **Runtime Execution:** Integrated backend code execution environment

---

## 💡 Features

### 1. 📝 Code Editor
- Real-time collaborative editing
- Syntax highlighting for multiple languages
- Monaco editor integration

### 2. 💬 Live Chat
- Text-based group chat within rooms
- User-based message distinction

### 3. ⚙️ Runtime Environment
- Compile and run code instantly
- Output display panel
- Currently supports C/C++, Python, Java, and JavaScript

### 4. 🧑‍🤝‍🧑 Collaboration Panel
- Real-time user presence
- File and tab management

### 5. 🎨 Drawing Board
- Free-hand sketching for brainstorming and teaching
- Supports multiple colors and shapes
